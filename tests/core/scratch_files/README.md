# tests/core/scratch_files

The test sources of `modules/core/scratch_files` kept in this folder. The suite prefix of a case gives its ctest label.

| File | Tests |
| --- | --- |
| `test_scratch_directory.cpp` | Tests that ScratchDirectory names a directory under the temporary one and removes it. |
| `test_scratch_file.cpp` | Tests that ScratchFile names a file under the temporary directory and removes it. |
