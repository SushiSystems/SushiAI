# tests/core/autograd/rules/test_loss/test_gradients.cpp


Suites: `Medium_Autograd`.

Tests the backward rules of the fused log-softmax and negative log-likelihood against central differences in FLOAT64, through the `GradientProbe` of `tests/support/gradient_probe.hpp`. The method is described in [`tests/core/autograd/README.md`](../../README.md).

## FusedCrossEntropyAgainstOneHotTargets

The gradient of the mean NLL with respect to the logits is (softmax - Y) / N. It is emitted as
one fused rule and not by differentiating the seven-op log-softmax recipe, so it needs its own
numeric proof.
