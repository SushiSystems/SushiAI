## What the plan did not predict

- `cli/pyproject.toml` has no `[project.optional-dependencies]` table, so there was no declared
  extra to reach for; `pytest` itself had to be installed by hand into the check environment.
- 9 of the 30 collected tests fail on this machine for a reason unrelated to `sushicore`: a
  stale or mismatched SYCL kernel in the existing `build/` tree. This is a pre-existing
  environment condition, not something this task's change caused or can fix without running the
  build system, which is out of scope here.
